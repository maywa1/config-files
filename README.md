# NixOS configuration

NixOS + Home Manager configuration for the `nixie` host.

## Layout

```
flake.nix                     Flake inputs and outputs
nixos/
  configuration.nix           Entry point; imports every system module
  hardware-configuration.nix  Generated by nixos-generate-config
  modules/                    System-wide configuration
home/maywai/
  home.nix                    Home Manager entry point for user maywai
  packages.nix                User-side packages
  zsh.nix                     User-side shell configuration
dotfiles/                     Config files synced with ~/.config
```

System services, setuid wrappers, fonts, and XMonad's native libraries live in
`nixos/modules/`. Anything a user runs interactively belongs in
`home/maywai/packages.nix`. The Home Manager integration itself is wired up in
`nixos/modules/home-manager.nix`.

`nixos-rebuild switch` activates the system **and** the Home Manager
configuration, so `deploy.sh` and `quick-update.sh` update both.

## Updating

`deploy.sh` syncs dotfiles, updates flake inputs, rebuilds the system and Home
Manager, commits, and pushes:

```bash
./deploy.sh "commit message"
```

`quick-update.sh` does the same but stops after committing:

```bash
./quick-update.sh "commit message"
```

To update only the user environment (packages, shell, user services) without
touching the system configuration:

```bash
./home-update.sh
```

That runs `nix flake update` and then `home-manager switch --flake .#maywai`.
You can skip the input update and just apply the current lock file with:

```bash
nix run .#home-manager -- switch --flake .#maywai
```

To rebuild the system without updating inputs or committing:

```bash
sudo nixos-rebuild switch --flake .#nixie
```

To format Nix files without touching `dotfiles/`:

```bash
nix fmt flake.nix nixos/configuration.nix nixos/modules home
```

## Dotfiles

`apply-dotfiles.sh` syncs the contents of `dotfiles/` with `~/.config`:

- If a config exists in `~/.config`, it is copied into the repository.
- If it does not exist, the repository version is copied into `~/.config`.

```bash
./apply-dotfiles.sh
```
